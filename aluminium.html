說明

這個工具在做什麼

場地要做假牆：牆面是木板，背後用鋁擠框撐起來，框上下用頂撐頂住天花板（梁）和地板。

你在 Fusion 把場地建好模，畫出要包的牆在哪裡、門窗在哪裡，匯入這裡。工具會自動：

  1. 沿著每一段牆排木板：公規板盡量用滿，剩下的餘數集中成特規板，放在轉角那一端。
  2. 把相鄰的板 2～3 片分成一組，每組做一個鋁擠框；框寬盡量統一，讓鋁擠長度種類越少越好。
  3. 算出每一組要的頂撐、掛具、五金和門窗鉸鏈。
  4. 產出一整份單子：給工廠出料（鋁擠料號、木板裁切），給工班組裝與放樣（組裝表、現場定位），給貼皮和大圖輸出（貼皮尺寸）。

木板是公規，跨場地重複使用；鋁擠每個場地照現場裁切，單支不超過 3 m，裝好後固定在場地不拆。

模型和設定只在你的瀏覽器裡處理，不會上傳。

常用名詞

段落 R1、R2…
一段直的牆。編號沿著你畫的鋁擠路徑方向排。
組（框）R7-F1
一個鋁擠框和掛在上面的那幾片板。F 編號沿段落方向遞增。
上板／下板
每一欄板分上下兩片，中間由 3060 中料撐住。
公規板／特規板
公規是固定尺寸、跨場地共用；特規是這個場地才裁的，通常在轉角或門窗旁邊。
料號 A、B、C…
同一種型材、同一個長度用同一個字母。叫料時請廠商把字母寫在每支料上，現場照字母挑料。
內角／外角／開放端
兩面牆夾著室內是內角；牆角凸向室內是外角；牆沒接到別的牆是開放端，會加側封板收邊。
基準轉角
相鄰兩段墨線（框背面線）的交點，現場所有位置都從這裡量。
框頂
全場框頂一樣高，由全場最低的梁底決定。

從模型到單子，照這個順序做

  1. 在 Fusion 準備模型。
    • 房間照實際建模：牆、地板、天花板、梁。頂撐會量到這些面，梁漏畫就會算錯。
    • 用草圖畫出要包牆的位置，薄擠出成曲面本體，本體名稱要含「鋁擠路徑」。線只要畫在大概位置：工具會把每段轉成互相垂直，靠近牆的線會自動貼到「型材背面離牆」的距離。不要包的地方（例如樓梯口）就不要畫。
    • 門窗用本體標出位置，名稱含「隱藏門」是隱藏門、含「門」是逃生門（留開口）、含「窗」是維修窗。
    • 房間和這些本體一起匯出成 STEP。
  2. 匯入。按上方「匯入空間」選 STEP。左邊「01 空間與牆面」會列出每一段 R 的長度、兩端是內角、外角還是開放端；3D 裡的橘線是段落位置。
  3. 有設定檔就載入。左邊最下面「圖層與專案」→「載入配置設定」。先載設定、或先匯入模型都可以。同一台電腦會自動存檔，下次打開直接回到上次的狀態。
  4. 檢查門窗。CAD 標記會自動帶入。要改就在 3D 的木板上按右鍵；門寬在「05 門窗」填。詳見「門窗」分頁。
  5. 調參數。大多照預設就好。改了會自動重排（「參數改變後自動更新」有勾時）。每個參數的意思見「參數」分頁。
  6. 看結果。按下方「展開配置結果」。有排不出來的地方，會寫在「框與門窗」分頁最上面和最下方的狀態列，照著改參數或門窗。
  7. 先做測試牆（建議）。在結果列的「料單範圍」填幾組，例如一兩段牆，只出這幾組的料單，先做起來驗證。
  8. 匯出。料單 PDF 給工廠和工班（按下去先勾要印哪些，給木工的按「木工裁切」），貼皮 PDF 給貼皮師傅和大圖輸出，CSV 用 Excel 開，3MF 是 3D 模型。
  9. 存設定。「儲存參數與門窗」存成 JSON 檔，要交給別人或換電腦用。設定檔不含模型，要連同原始 STEP 一起給。
  10. 到現場。照料單 PDF 的「現場定位」彈墨線、立框，照「組裝表」組框。詳見「叫料與現場施工」分頁。

沒有畫鋁擠路徑的模型（牆面模式）

OBJ、STL、3MF，或是沒有「鋁擠路徑」本體的 STEP，會改用牆面模式：

  • 在「01 空間與牆面」勾選要做的牆（或直接點 3D 裡的牆面）。
  • 在「02 生成邊界」調每面牆的起點、終點、底高、頂高；橘線是生成範圍。方向反了按「翻轉這面牆的生成方向」。
  • OBJ／STL 沒有單位，要在 01 選對單位和向上軸。

「示範房間」就是用這個模式，可以先拿它熟悉操作。

OBJ／STL 單位、模型向上軸
只影響 OBJ／STL。STEP 和 3MF 照檔案本身的單位讀；Fusion 是 Z 向上。
段落／牆面清單
路徑模式列出每一段 R；牆面模式在這裡勾選要做的牆。

02 生成邊界（只有牆面模式）

每面牆的起點、終點、底高、頂高，橘線是生成範圍，高度以那面牆的底部為零；門窗缺口會自動保留。「翻轉這面牆的生成方向」改排板的方向。路徑模式不用這一區，段落由鋁擠路徑決定。

03 公規板

板寬、上板高、下板高
公規板尺寸。公規跨場地共用，定案後就不要再改；場地比較矮時用補板處理。
每框片數
一組框掛幾欄板。「自動」會 2、3 片混用，讓組數最少、每支鋁擠不超過 3 m。
板高依上下預留自動計算
只有在試算新公規時才勾。
依原板推薦公規
依原板尺寸反推公規候選，比較框頂高度和特規數，點選就套用。梁太低、框頂超出時用它降板高。

04 裝配參數

上方腳墊、下方腳墊
頂天花板、立地的頂撐各用哪一款腳墊。
板底離地
下板底邊離地面多高。
下板突出框底
下板往下超出鋁框底的長度，用來遮住框底和腳墊。
木板水平縫隙
左右相鄰兩片板之間的縫。
長掛具、短掛具長度
板背面的掛具。放得下就用長的，窄板用短的，再放不下就做特規長度。
框現場滑動餘量
掛具兩端到立柱留的空間，讓框在現場可以左右挪一點對位（每側）。
牆板厚度
木板的厚度。
型材背面離牆
鋁框背面到後面那道牆的距離；要大於腳座固定塊凸出的量。
最窄特規板
特規板最窄能多窄。餘數比這個還窄時，會拿掉一片公規，合成一片比較寬的特規。
板頂到天花板最小預留
板頂到最低梁底至少要留的空間。
螺桿調整餘量
頂撐挑延長桿時多留的長度，寧長勿短。
合板鋸路
裁合板時鋸片吃掉的寬度，排裁切圖用。
現成 M10 螺桿長度
手邊買得到的螺桿長度，用逗號分隔。延長桿只從這些挑，現場不裁。

05 門窗

列出目前所有門窗，可以填門寬。詳見「門窗」分頁。

三種門窗

隱藏門
一片門板，正面跟牆板齊平，往室內開。鉸鏈鎖在旁邊那組框的立柱上。
維修窗
上板或下板其中一排換成窗扇。窗洞碰到兩欄以上，就做左右對開兩扇。
逃生門
留開口、不做板，兩側加門套收邊。只能從 CAD 標記帶入。

怎麼設定

  1. CAD 標記自動帶入。匯入時，名稱含「隱藏門」「門」「窗」的本體會變成對應的門窗。
  2. 在 3D 木板上按右鍵：可以設成一般牆板、隱藏門（鉸鏈在左或右）、維修窗（鉸鏈在左或右，做在你點的那一排）。「左右」都是站在室內面對牆看。
  3. 還原這段的 CAD 標記：右鍵選單最下面，改亂了可以整段回到 CAD 的設定。
  4. 門寬：在「05 門窗」的清單填。留空就用標記的寬度（碰到內角會自動停在隔壁牆的板前面）；填數字就是指定門寬，鉸鏈那一側不動，從鎖的那一側伸縮。維修窗照板格，不能填寬度。
  5. 改錯了：按 Ctrl + Z 一步一步復原。

門窗排不下時（例如鎖側只剩一條放不下板的窄縫），狀態列會直接告訴你門寬可以填多少。

料單範圍：只出一部分

  • 空白：全場。
  • 填框或段落編號：只算那幾組，例如 R4-F1 R4-F2，或整段 R5。寫成「R6 F1」也可以。
  • 開頭加「除」：算其餘全部，例如 除 R4 R5，之後補料用。
  • 鋁擠料號照全場排，所以部分料單的字母會跳號；同一個字母在每一批都是同一個長度。測試牆加上其餘，數量剛好等於全場。
  • 現場定位會保留全場的墨線，因為轉角要靠相鄰段的線才定得準。

長度單位與小數

可以切 mm、cm、英吋，小數 1 位或 2 位。只換結果與料單，參數輸入一律 mm。螺絲、腳墊、螺桿、掛具、板厚這些現成品的規格維持 mm。英吋給工廠裁料請用小數 2 位。

叫料

  • 鋁擠：照料單「鋁擠」那一節叫，請廠商把料號字母寫在每一支料上。
  • 木板：照「木板」和「合板裁切」裁，給木工時勾選視窗按「木工裁切」；公規板第一次做好之後跨場地共用，之後只裁特規。
  • 五金：照「五金」買，已經分成結構件、頂撐、螺絲螺帽、門窗四組，一組一組對。
  • 頂撐：「頂撐做法」寫每一種間隙用哪款腳墊、要不要加延長桿。

放樣：現場定位

  1. 所有位置都從基準轉角量起：相鄰兩段墨線（框背面線）的交點。
  2. 先把全場的墨線一次彈好，用表上的「墨線長」驗線。
  3. 照表上「框外緣距轉角」「門窗距轉角」標出每一組框和門窗的位置；「框背面離後牆」用來確認離牆距離。
  4. 高度用雷射水平儀打框頂線，腳墊調到框頂碰線。

組裝：組裝表

  • 每一組框一行：上橫、下橫、左右立柱、中料各用哪個料號，照字母挑料，不用量長度。
  • 同一行寫這組要的角件、掛具、上壓板數量、頂撐，以及掛哪幾片板（特規板寫編號）。
  • 同一組的頂撐有的要加延長桿、有的不用時，會逐支寫出離基準轉角多遠。

先做測試牆

用「料單範圍」先出幾組的料單，做起來確認尺寸、組法都沒問題，再用「除 …」出其餘的補料單。
